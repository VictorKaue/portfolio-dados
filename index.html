Sobre Mim

Engenheiro de Dados

Transformando dados em soluções eficientes e escaláveis.

Sou estudante de Ciência da Computação e Ciência de Dados, com foco em Engenharia de Dados e um background sólido em desenvolvimento mobile (iOS). Tenho grande interesse em criar pipelines de dados eficientes, explorar Machine Learning e construir arquiteturas escaláveis.

Minha experiência une o processamento e a análise de dados com Python, SQL, Apache Airflow e Docker ao desenvolvimento back-end em TypeScript/NestJS, FastAPI e Flask, além de interfaces nativas em Swift e SwiftUI. Essa vivência me permite compreender todo o ciclo de vida de um produto, desde a extração do dado até a experiência final do usuário.

Atualmente, busco aprofundar meus conhecimentos em infraestrutura de dados (ETL/ELT, OLAP/OLTP, processamento distribuído com PySpark e Databricks) enquanto continuo aplicando boas práticas — testes automatizados, CI/CD e observabilidade — na construção de soluções reais e eficientes.

Esse lado iOS não fica só no currículo: é ele que sustenta o Liber Intercâmbio, publicado na App Store com Machine Learning rodando on-device (CoreML/CreateML), e o Matcha, onde entreguei a experiência nativa em SwiftUI por trás dos dados que processo no back-end.

iOS Dados

Liber Intercâmbio

Projeto pessoal ponta a ponta. App iOS para centralizar informações sobre intercâmbio, com Machine Learning on-device. Desenvolvo sozinho todo o pipeline de dados (ELT): um crawler coleta dados brutos para um Data Lake local (MinIO), o Gemini estrutura o conteúdo com validação via Pydantic — com deduplicação por hash SHA-256 do conteúdo para evitar chamadas pagas redundantes à API — e o Airflow orquestra a carga em PostgreSQL. Isolei falhas de extração por IA em SAVEPOINTs por item, para que um único registro inválido não derrube o lote inteiro.
